# Bank ESG Assessment Framework (Construction Industry)

> Mock questionnaire for Green Finance Hackathon POC

## Purpose

This questionnaire represents the bank's **internal ESG assessment
framework**. The AI evaluates uploaded company reports against these
questions to produce an explainable ESG assessment.

## Assessment Status

  Status                    Points
  --------------------- ----------
  Fully Addressed              100
  Partially Addressed           50
  Not Disclosed                  0
  Not Applicable          Excluded

# Scoring Formula

For each question:

Contribution = Weight × (Status Points / 100)

Overall ESG Score = Sum of Contributions / Sum of Applicable Weights ×
100

------------------------------------------------------------------------

# Recommendation Bands

       Score Recommendation
  ---------- ----------------------------
     80--100 Eligible for Green Finance
      60--79 Conditionally Eligible
      40--59 Further Review Required
    Below 40 Not Eligible

------------------------------------------------------------------------

# Explainability

Each assessment must include: - Assessment status - Supporting
evidence - Source document - Page number - Confidence score - Reasoning
